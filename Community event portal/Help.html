Getting Started
Go to the Events section on the homepage. Use the search bar to search by name or location, or click the category pills — All, Music, Workshop, Sports, or Food — to filter.
Click the ☽ / ☀ button in the top-right corner of any page. Your preference is saved automatically and will be remembered on your next visit.
The portal is completely free. Some events have a small entry fee — Sports events are free, Food events are ₹50, Music is ₹150, and Workshops are ₹200. Fees are shown on each event card and on the registration form when you select an event type.

Events & Gallery
Each event card shows a live status badge — ✔ Open means seats are available, ✘ Full means it's at capacity. The admin table in the Bulletin section also shows availability for all events.
Double-click any image in the Gallery section to open it full-screen. Click anywhere outside the image or the ✕ button to close.
Make sure the images/ folder is in the same directory as index.html. If running locally, use a dev server like Live Server in VS Code rather than opening the file directly.
Troubleshooting
Theme is stored in localStorage, which doesn't persist on raw file:/// paths in some browsers. Serve the site over http://localhost for preferences to save correctly.
Click Allow when your browser asks for location permission. Geolocation also requires a secure context — it works on https:// or localhost, not plain file:/// paths.
Ensure index.html, styles.css, and script.js are all in the same folder. Try a hard refresh with Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac) to clear cached files.
